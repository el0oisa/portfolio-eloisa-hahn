# SUPERPROMPT — PORTFÓLIO PESSOAL AUTORAL



## Projeto completo de Front-end + Back-end + Supabase + Design System + Acessibilidade



Quero que você atue simultaneamente como:



* UX/UI Designer;

* Product Designer;

* UX Writer;

* Desenvolvedor Front-end;

* Desenvolvedor Back-end;

* Arquiteto de informação;

* Especialista em bancos de dados;

* Especialista em Supabase;

* Especialista em acessibilidade digital;

* Especialista em design systems;

* Especialista em responsive web design;

* Especialista em microinterações e motion design.



Sua tarefa é **PROJETAR E IMPLEMENTAR um sistema completo de PORTFÓLIO PESSOAL AUTORAL**, e não apenas criar um mockup ou uma interface visual.



O resultado deve ser uma aplicação funcional, responsiva, acessível, conectada ao Supabase e preparada para publicação.



---



# 1. OBJETIVO DO PROJETO



Desenvolver um sistema de portfólio pessoal no qual uma pessoa possa administrar seus próprios conteúdos por meio de uma área administrativa.



O proprietário do portfólio deverá conseguir cadastrar:



* nome do portfólio;

* apresentação pessoal;

* biografia;

* textos;

* categorias de projetos;

* projetos;

* imagens;

* vídeos do YouTube;

* arquivos de áudio;

* textos relacionados aos projetos;

* informações de contato;

* número de WhatsApp;

* links para redes ou plataformas externas, caso deseje.



Esses conteúdos deverão ser armazenados de forma persistente utilizando **Supabase**.



Nada importante deve depender apenas de dados mockados, arrays locais, localStorage ou conteúdo escrito diretamente no código.



Ao atualizar ou fechar o navegador, os conteúdos cadastrados deverão continuar existindo.



---



# 2. PRINCÍPIO CENTRAL



Este não deve ser um portfólio genérico criado a partir de um template visual pronto.



Ele deve funcionar como uma **infraestrutura para a criação de um portfólio autoral**.



Por isso, separar claramente:



1. CONTEÚDO;

2. ESTRUTURA;

3. DESIGN SYSTEM;

4. COMPORTAMENTO;

5. DADOS.



O aluno deverá conseguir modificar posteriormente sua linguagem visual sem precisar reconstruir todo o sistema.



---



# 3. TECNOLOGIAS



Utilize preferencialmente:



* React;

* TypeScript;

* CSS moderno;

* Supabase;

* Supabase Database;

* Supabase Auth;

* Supabase Storage.



Se o ambiente em que você estiver trabalhando exigir Next.js, Vite ou outra estrutura React compatível, adapte a implementação.



Priorize:



* código organizado;

* componentes reutilizáveis;

* semântica HTML;

* manutenção simples;

* separação de responsabilidades;

* bom desempenho;

* acessibilidade.



Não crie dependências desnecessárias.



---



# 4. SUPABASE

## Banco de dados



Persistência de:



* dados do portfólio;

* perfil;

* categorias;

* projetos;

* blocos de conteúdo;

* configurações;

* design system.
